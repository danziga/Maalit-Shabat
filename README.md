# מעלית שבת – נתניה

דף HTML עצמאי (ללא תלות באינטרנט, ללא שרת) שמחשב **בזמן אמת ולכל שנה** את זמני מעלית השבת, כניסת/יציאת שבת וזמן ערבית, לפי פרשת השבוע — בהתאם לזמני נתניה.

**[מעלית שבת - צפייה בדף](index.html)** · אתר חי: https://danziga.github.io/Maalit-Shabat/

## מה הדף עושה

בכל טעינה, הדף מזהה את השבת הקרובה (או הנוכחית, אם נטען בזמן שבת/חג) ומציג עבורה:

- כניסת שבת, יציאת שבת וזמן ערבית
- רשימת חלונות הזמן שבהם המעלית פועלת אוטומטית (עוצרת בכל קומה), מחולקת ל"ליל שבת" ו"יום שבת"

אפשר לבחור פרשה אחרת מתוך רשימה נפתחת (כל שבתות השנה העברית המוצגת), לדפדף לשנה עברית קודמת/הבאה בלי הגבלה, וללחוץ "השבת הקרובה" כדי לחזור לברירת המחדל האוטומטית.

### סימון שינויים

אם רשימת חלונות הפעלת המעלית של שבת מסוימת שונה מזו של השבת הקודמת, מופיעה תגית **"השתנה משבת קודמת"** ליד הכותרת, עם ציון כמה חלונות נוספו/הוסרו, והחלונות החדשים מסומנים בכתום ברשימה.

## איך זה מחושב — לתמיד, ולא רק לשנתיים

הדף לא מכיל טבלת נתונים קבועה לכמה שנים; הוא **בונה את הנתונים על אתר (on-demand)**, בג'אווהסקריפט טהור, לכל שנה עברית שמבקשים — עבר או עתיד, ללא הגבלת טווח. שלושה מנועים עצמאיים עושים את זה:

1. **לוח שנה עברי** — המרת תאריכים עברי↔לועזי וקביעת פרשת השבוע לכל שבת, מבוססים על אלגוריתם ה־[pyluach](https://pypi.org/project/pyluach/) (פורטו לג'אווהסקריפט ידנית). אומת ביחס ל-pyluach על פני **73,414 תאריכים** (1950–2150, יום-יום) ו-**11,534 שבתות** (5700–5920) — התאמה מלאה.
2. **שקיעה אסטרונומית** — נוסחת NOAA הסטנדרטית, לקואורדינטות נתניה (32.3328°N, 34.8600°E). כניסת שבת = כ-20 דקות לפני השקיעה, יציאת שבת = כ-30 דקות אחריה — היחס שזוהה בהשוואה לזמנים המקוריים בקובץ האקסל. אומת מול הספרייה `astral` על פני 30 שנה ומגוון עונות; סטייה ממוצעת כ-28 שניות, מקסימלית כ-66 שניות.
3. **לוח פעילות המעלית** — כאן אין נוסחה: מדובר בהחלטה תפעולית (איזה מנייני קבלת שבת, אילו הפסקות וכו'), לא בחישוב אסטרונומי. לכן הדף שומר "ספריית תבניות" של 57 השבתות/החגים בשנת **תשפ״ו** — השנה היחידה שעבורה קיים לוח מקורי מלא — ולכל שבוע אחר (בכל שנה) הוא בוחר את התבנית עם זמן כניסת השבת הקרוב ביותר (או, בחג, את התבנית של אותו חג בדיוק).

המשמעות: מבחינת דיוק, תשפ״ו עצמה מוצגת כעת גם היא דרך אותו מנוע מחושב (ולא כערכים "קפואים" מהאקסל), כדי שהדף כולו יתנהג באופן אחיד. ההבדל מהערכים המקוריים הוא לכל היותר דקה אחת.

## מבנה הקוד

כל הלוגיקה, הסגנון וספריית התבניות ארוזים בקובץ HTML יחיד (`index.html`) — בלי תלות בספריות חיצוניות, בלי קריאות רשת, בלי build step. אפשר לפתוח אותו ישירות בדפדפן, או לארח אותו (כרגע דרך GitHub Pages).

בתוך התג `<script>` בקובץ:
- לוח שנה עברי + פרשות + גימטריה לשם השנה
- חישוב שקיעה
- ספריית התבניות (`TEMPLATES`, מבוססת תשפ״ו)
- הרכבת רשימת השבתות/החגים לשנה עברית נתונה
- ממשק המשתמש (בחירה, דפדוף שנים, סימון שינויים)

### עדכון לוח הפעילות (אם המדיניות משתנה)

אם קהילה/ועד הבית מחליטים על לוח פעילות מעלית שונה, יש לעדכן את מערך ה־`TEMPLATES` (57 האובייקטים בתחילת ה־script) בהתאם — כל שאר החישובים (תאריכים, כניסת/יציאת שבת) ימשיכו לעבוד ללא שינוי, לכל שנה.
